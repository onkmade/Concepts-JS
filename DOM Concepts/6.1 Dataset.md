### Question:Could explain the proper and actual use of data on a website and provide an actual example? (In a short paragraph)

`data-*` attributes are the proper, standard way to store custom data directly on HTML elements for use by JavaScript. They allow you to attach arbitrary information (like IDs, statuses, categories, or configuration values) to any element without misusing existing attributes or classes. The browser ignores them completely for rendering and styling, but JavaScript can easily read them via the `dataset` property. This keeps your HTML clean, semantic, and extensible while giving your scripts the extra information they need to work intelligently.

A real-world example is an e-commerce product card:

```html
<div class="product-card" data-product-id="789" data-price="49.99" data-category="electronics" data-in-stock="true">
  <img src="headphones.jpg" alt="Wireless Headphones">
  <h3>Wireless Headphones</h3>
  <p class="price">$49.99</p>
  <button class="add-to-cart">Add to Cart</button>
</div>
```

In JavaScript, when the "Add to Cart" button is clicked:

```js
document.querySelectorAll(".add-to-cart").forEach(button => {
  button.addEventListener("click", function() {
    const card = this.closest(".product-card");
    const product = {
      id: card.dataset.productId,         // "789"
      price: Number(card.dataset.price),  // 49.99
      category: card.dataset.category,    // "electronics"
      inStock: card.dataset.inStock === "true"
    };
    addToCart(product); // custom function
  });
});
```

This approach is clean, performant, and widely used on modern websites because it keeps custom data right where it belongs—on the element itself—without polluting classes or inventing non-standard attributes.
