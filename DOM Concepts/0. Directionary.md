# Small 1 line description of following content

- `Nodelist` - A collection of nodes, often returned by methods like `document.querySelectorAll()`. It behaves like an array but is not a true array.
- `Node` - The most basic unit in the DOM tree. It can be an element, text, comment, etc.
- `Element` - A type of node that represents an HTML element. It can have attributes, styles, and children.
- `Attribute` - A property of an HTML element that provides additional information about that element (e.g., `id`, `class`, `src`).
- `Text Node` - A node that contains only text. It is a child of an element node.
- `Parent Node` - A node that has one or more child nodes.
- `Child Node` - A node that is a direct descendant of another node (its parent).
- `Sibling Nodes` - Nodes that share the same parent node.
- `Document Object Model (DOM)` - A programming interface for web documents. It represents the page so that programs can change the document structure, style, and content.
- `DOM Tree` - The hierarchical structure of nodes in a document, starting from the root `document` node down to individual elements and text nodes.
- `Event` - An action or occurrence that happens in the system you are programming, which the system tells you about so your code can respond to it (e.g., clicks, key presses).
- `Event Listener` - A function that waits for a specific event to occur on a specific element and executes when that event happens.
- `HTMLCollection` - A live collection of HTML elements, often returned by methods like `document.getElementsByTagName()`. It updates automatically when the document changes.
