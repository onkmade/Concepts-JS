### Boolean Properties in the DOM – True/False States That Control Behavior

In the DOM, certain element properties are **boolean** — they are either `true` or `false` — and directly reflect or control the state of HTML attributes like `checked`, `disabled`, `selected`, `required`, etc. These properties are **live**: changing them instantly updates the element's appearance and behavior in the browser, and vice versa. They are the most efficient way to read or set binary states (on/off) for form controls and interactive elements. Unlike regular attributes (which are strings), boolean properties are actual JavaScript booleans, making them perfect for conditional logic (`if (input.checked) { ... }`). Always prefer the property over `getAttribute()`/`setAttribute()` for these because it's faster, cleaner, and automatically syncs with the DOM state.

### Common Boolean Properties (The Ones You’ll Use Most)

| Property            | Element(s)              | What it controls                              | Example Use Case                          |
|---------------------|-------------------------|-----------------------------------------------|-------------------------------------------|
| `.checked`          | `<input type="checkbox">`, `<input type="radio">` | Whether the box is ticked                     | Form submission, toggle switches          |
| `.disabled`         | Buttons, inputs, select, textarea | Whether the element is interactive            | Disable submit until form valid           |
| `.selected`         | `<option>` in `<select>` | Whether the option is chosen                  | Pre-select dropdown values                |
| `.required`         | Form inputs             | Whether the field must be filled              | Custom validation logic                   |
| `.readOnly`         | Inputs, textarea        | Whether user can edit the value               | Display mode vs edit mode                 |
| `.multiple`         | `<select>`              | Allows multiple option selection              | Multi-select dropdowns                    |
| `.autoplay`         | `<video>`, `<audio>`    | Starts playing automatically                  | Video players                             |
| `.loop`             | `<video>`, `<audio>`    | Loops the media                               | Background videos                         |
| `.muted`            | `<video>`, `<audio>`    | Audio is muted                                | Auto-play videos without sound            |

### Code Example – Checkbox Group with Boolean Properties

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Boolean Properties Practice</title>
  <style>
    body { font-family: system-ui; padding: 40px; max-width: 500px; margin: auto; }
    label { display: block; margin: 10px 0; font-size: 18px; }
    #status { margin-top: 20px; font-weight: bold; }
    button { padding: 10px 20px; margin-top: 20px; font-size: 16px; }
  </style>
</head>
<body>
  <h2>Select Your Favorite Languages</h2>
  <label><input type="checkbox" id="js"> JavaScript</label>
  <label><input type="checkbox" id="py"> Python</label>
  <label><input type="checkbox" id="css"> CSS</label>

  <button id="checkBtn">Check Selected</button>
  <button id="disableBtn">Disable All</button>
  <p id="status"></p>

  <script>
    const jsBox = document.getElementById('js');
    const pyBox = document.getElementById('py');
    const cssBox = document.getElementById('css');
    const status = document.getElementById('status');
    const checkBtn = document.getElementById('checkBtn');
    const disableBtn = document.getElementById('disableBtn');

    // Check selected languages
    checkBtn.addEventListener('click', () => {
      const selected = [];
      if (jsBox.checked) selected.push('JavaScript');
      if (pyBox.checked) selected.push('Python');
      if (cssBox.checked) selected.push('CSS');

      status.textContent = selected.length ? 
        `You know: ${selected.join(', ')}` : 
        'No languages selected';
    });

    // Toggle disabled state
    disableBtn.addEventListener('click', () => {
      const isDisabled = !jsBox.disabled; // flip current state

      jsBox.disabled = isDisabled;
      pyBox.disabled = isDisabled;
      cssBox.disabled = isDisabled;

      disableBtn.textContent = isDisabled ? 'Enable All' : 'Disable All';
    });
  </script>
</body>
</html>
```

### How It Works

- `.checked` — true if checkbox is ticked.
- `.disabled = true/false` — instantly disables/enables inputs.
- Reading the boolean directly in `if (jsBox.checked)` — clean conditional logic.

These boolean properties are your direct line to form state and interactivity.
