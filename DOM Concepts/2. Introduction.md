The Document Object Model (DOM) tree is a hierarchical representation of an HTML document created by the browser. It structures the entire webpage as a tree of nodes, where each node represents a part of the document — such as an element, attribute, or text. The topmost node is the `document` object itself, followed by the root element `<html>`, which branches into `<head>` and `<body>`. Every nested tag becomes a child node of its parent tag, forming a parent-child relationship that mirrors the HTML nesting. This tree structure allows JavaScript to navigate, read, modify, add, or remove parts of the page dynamically.

In the DOM tree, there are different types of nodes: **element nodes** (for tags like `<div>`, `<p>`), **text nodes** (for actual text inside elements), **attribute nodes** (for attributes like `id`, `class`), and **comment nodes** (for `<!-- comments -->`). The most commonly manipulated are element and text nodes. Parent nodes can have multiple children, but each child has only one parent. Siblings are nodes at the same level (e.g., multiple `<li>` inside a `<ul>`). This tree enables traversal methods like `parentNode`, `childNodes`, `firstChild`, `lastChild`, `nextSibling`, and `previousSibling`, making it possible to move around the structure programmatically.

The DOM tree is **live** — any change made via JavaScript (like adding a new element or changing text) instantly reflects in the rendered page. This dynamic nature is what makes web pages interactive. Understanding the tree structure is essential because DOM manipulation always follows this hierarchy: you select a node, then access its children, parents, or siblings to make changes.

### DOM Tree Structure in YAML (Example)

```yaml
document:
  nodeType: "#document"
  childNodes:
    - html:
        nodeType: "ELEMENT_NODE"
        tagName: "html"
        childNodes:
          - head:
              nodeType: "ELEMENT_NODE"
              tagName: "head"
              childNodes:
                - title:
                    nodeType: "ELEMENT_NODE"
                    tagName: "title"
                    childNodes:
                      - text: "My Page Title"
          - body:
              nodeType: "ELEMENT_NODE"
              tagName: "body"
              attributes:
                class: "main-body"
              childNodes:
                - h1:
                    nodeType: "ELEMENT_NODE"
                    tagName: "h1"
                    attributes:
                      id: "main-title"
                    childNodes:
                      - text: "Welcome to JavaScript"
                - p:
                    nodeType: "ELEMENT_NODE"
                    tagName: "p"
                    childNodes:
                      - text: "This is a paragraph."
                - ul:
                    nodeType: "ELEMENT_NODE"
                    tagName: "ul"
                    childNodes:
                      - li:
                          nodeType: "ELEMENT_NODE"
                          tagName: "li"
                          childNodes:
                            - text: "Item 1"
                      - li:
                          nodeType: "ELEMENT_NODE"
                          tagName: "li"
                          childNodes:
                            - text: "Item 2"
```

This YAML representation shows the nested, tree-like structure: each element has children, and text is stored as text nodes. In real DOM, you access this using properties like `.childNodes`, `.children` (elements only), `.parentNode`, etc.
