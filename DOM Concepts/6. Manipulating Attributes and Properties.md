### Manipulating Attributes and Properties in the DOM

In the DOM, every HTML element has **attributes** (the things you write in the HTML tag, like `id`, `class`, `src`, `href`, `value`, `disabled`, etc.) and **properties** (the live, JavaScript-accessible values of the element object). While they often overlap, they are not exactly the same thing. Attributes are the initial values written in the HTML markup, stored as strings. Properties are the current, live values in the DOM object, which can be of any type (string, boolean, number, object) and can change independently of the markup. Manipulating attributes and properties is essential for tasks like changing image sources, updating links, handling form inputs, enabling/disabling buttons, or adding custom data attributes.

The key difference is that **attributes** are static and always strings (even if they look like booleans or numbers in HTML), while **properties** are dynamic and reflect the current state of the element in memory. Changing a property usually updates the element immediately, and in most cases, it also syncs back to the attribute (but not always). For standard attributes like `id`, `class`, `src`, `value`, etc., it's recommended to use the corresponding **property** directly because it's faster, type-correct, and reflects the live state. For custom attributes (starting with `data-`) or non-standard ones, you use attribute methods.

### Working with Properties (Preferred for Standard Attributes)

Most common attributes have direct property equivalents on the element object.

```js
// HTML: <img id="avatar" src="old.jpg" alt="Profile">
//       <input type="text" value="initial">

const img = document.getElementById("avatar");
const input = document.querySelector("input");

// Reading properties
console.log(img.src);     // full URL: "https://example.com/old.jpg"
console.log(input.value); // "initial"

// Changing properties (updates the element immediately)
img.src = "new.jpg";      // changes image source
input.value = "new text"; // changes input value
```

Other common properties:
- `element.id`
- `element.className` (string — avoid; use `classList` instead)
- `element.href` (for `<a>`)
- `element.disabled` (boolean for buttons/inputs)
- `element.checked` (boolean for checkboxes)

### Working with Attributes (For Custom or Non-Standard)

Use these methods when dealing with attributes that don't have direct properties or when you need the original HTML value.

- `getAttribute(name)` — read attribute value
- `setAttribute(name, value)` — set or change attribute
- `hasAttribute(name)` — check if attribute exists
- `removeAttribute(name)` — delete attribute

```js
// HTML: <div data-user-id="123" aria-label="Close">

const div = document.querySelector("div");

// Reading custom attribute
console.log(div.getAttribute("data-user-id")); // "123"

// Setting/changing
div.setAttribute("data-status", "active");

// Checking existence
console.log(div.hasAttribute("aria-label")); // true

// Removing
div.removeAttribute("aria-label");
```

### Special Case: Custom Data Attributes (`data-*`)

The modern way to store custom data on elements is with `data-*` attributes. JavaScript provides a convenient `dataset` property to access them (camelCase conversion).

```html
<div id="product" data-product-id="456" data-price="29.99" data-in-stock="true"></div>
```

```js
const product = document.getElementById("product");

// Using dataset (recommended for data-* attributes)
console.log(product.dataset.productId); // "456"
console.log(product.dataset.price);     // "29.99"
console.log(product.dataset.inStock);   // "true" (string!)

// Setting new data
product.dataset.category = "electronics";

// Removing data attribute
delete product.dataset.inStock;
```

Note: `dataset` values are always strings — convert if needed (e.g., `Number(product.dataset.price)`).

### Best Practices Summary

- **Use properties** (`element.src`, `element.value`, `element.checked`, etc.) for standard attributes — faster and live.
- **Use `classList`** for classes (`.add()`, `.remove()`, `.toggle()`, `.contains()`) — never manipulate `className` string directly.
- **Use `dataset`** for custom `data-*` attributes — clean and modern.
- **Use attribute methods** (`getAttribute`, `setAttribute`) only for non-standard attributes or when you need the original HTML string value.
- Avoid `innerHTML` for simple attribute changes — it's overkill and risky.

### Quick Example Combining All

```html
<img id="photo" src="placeholder.jpg" data-index="0" alt="Photo">
```

```js
const photo = document.getElementById("photo");

// Property (live)
photo.src = "new-photo.jpg";

// Dataset (custom data)
console.log(photo.dataset.index); // "0"
photo.dataset.index = "1";

// Attribute (original HTML value)
console.log(photo.getAttribute("alt")); // "Photo"
photo.setAttribute("alt", "New description");
```
