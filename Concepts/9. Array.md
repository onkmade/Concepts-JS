# Array

Arrays in JavaScript are one of the most powerful and commonly used data structures in web development. An array is an **ordered collection** of values, where each value (called an **element**) is stored at a numeric **index** starting from 0. Unlike objects (which use named keys), arrays use numbered positions, making them perfect for lists: todo items, shopping cart products, search results, comments, messages, or any sequence of data. Arrays are actually special objects under the hood, but they come with built-in methods and a `.length` property that automatically updates.

You create an array using square brackets `[]`. Elements can be any type — numbers, strings, booleans, objects, even other arrays (nested) or functions:

```js
const fruits = ["apple", "banana", "orange"];
const mixed = [42, "hello", true, { name: "Kiuru" }, [1, 2, 3]];
const empty = [];
```

Access elements by index: `fruits[0]` → "apple", `fruits[1]` → "banana". The last element is always at `fruits[fruits.length - 1]`. Arrays are **mutable** — you can change elements directly: `fruits[1] = "mango";`. Use `.push(item)` to add to the end, `.pop()` to remove from the end, `.unshift(item)` to add to the beginning, and `.shift()` to remove from the beginning. These four are the most basic mutating methods.

The real power comes from **higher-order methods** that let you transform, filter, search, and loop without writing manual for loops:

- `.forEach()` — executes a function for each element (great for side effects like DOM updates)
- `.map()` — creates a new array by transforming each element (perfect for rendering lists)
- `.filter()` — creates a new array with only elements that pass a test
- `.find()` — returns the first element that matches a condition (or undefined)
- `.some()` / `.every()` — check if some/all elements satisfy a condition (return true/false)
- `.reduce()` — combines all elements into a single value (sums, averages, objects, etc.)

These methods don't mutate the original array (except a few like `.sort()`), making your code more predictable.

Arrays also support spreading with `...`: `const moreFruits = [...fruits, "grape", "kiwi"];` creates a new array. You can combine arrays: `const all = [...fruits, ...veggies];`.

```javascript
// Empty array
const empty = [];

// Array with values
const fruits = ["apple", "banana", "orange", "mango"];
const numbers = [10, 20, 30, 40];
const mixed = ["Kiuru", 21, true, { city: "Helsinki" }];

// Common in real apps: array of objects
const tasks = [
  { task: "Learn arrays", done: false },
  { task: "Practice push/pop", done: false },
  { task: "Build project", done: true }
];

```
### methods in arrays
```javascript
// Adding elements
fruits.push("grape"); // Add to end
fruits.unshift("kiwi"); // Add to start
// Removing elements
fruits.pop(); // Remove from end
fruits.shift(); // Remove from start
// Accessing elements
const firstFruit = fruits[0]; // "apple"
const lastFruit = fruits[fruits.length - 1]; // "mango"
// Looping through arrays
fruits.forEach((fruit, index) => {
  console.log(`${index}: ${fruit}`);
});
// Transforming arrays
const upperFruits = fruits.map(fruit => fruit.toUpperCase());
// Filtering arrays
const longFruits = fruits.filter(fruit => fruit.length > 5);
// Finding elements
const mango = fruits.find(fruit => fruit === "mango");
// Checking conditions
const hasBanana = fruits.some(fruit => fruit === "banana");
const allLong = fruits.every(fruit => fruit.length > 3);
// Reducing arrays
const totalLength = fruits.reduce((sum, fruit) => sum + fruit.length, 0);
```
