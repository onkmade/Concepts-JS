### The `.forEach()` Method in Depth

The `.forEach()` method is one of the most commonly used array methods in JavaScript. It allows you to loop through each element in an array and execute a provided function once for every element. It is perfect for situations where you want to perform an action on each item (called a "side effect"), such as logging to the console, updating the DOM, or calling another function. Unlike some other array methods, `.forEach()` does **not** return a new array and does **not** mutate the original array unless you explicitly change elements inside the callback. It simply iterates from index 0 to the last index and stops — there is no way to break early like in a regular `for` loop.

The beauty of `.forEach()` lies in its readability and simplicity compared to traditional `for` loops. It removes the need to manage an index variable or use `.length` manually, making your code cleaner and less error-prone. This method is widely used in real web development for tasks like rendering lists of items (e.g., displaying posts, products, or comments on a page) or processing form data.

### Basic Syntax

```js
array.forEach(callbackFunction);

// The callback function can take up to 3 parameters:
// 1. currentElement (required)
// 2. index (optional)
// 3. arrayItself (optional)
array.forEach((element, index, array) => {
  // your code here
});
```

### Detailed Examples

**Example 1: Basic usage with only the element**

```js
const fruits = ["apple", "banana", "orange", "mango"];

fruits.forEach(fruit => {
  console.log(fruit);
});
// Output:
// apple
// banana
// orange
// mango
```

Here, the callback receives only the current element (`fruit`). This is the most common simple case.

**Example 2: Using element and index**

```js
fruits.forEach((fruit, index) => {
  console.log(`${index + 1}. ${fruit.toUpperCase()}`);
});
// Output:
// 1. APPLE
// 2. BANANA
// 3. ORANGE
// 4. MANGO
```

The `index` parameter is useful for numbering items or conditional logic based on position.

**Example 3: Using all three parameters**

```js
fruits.forEach((fruit, index, fullArray) => {
  console.log(`Item: ${fruit}, Position: ${index}, Total items: ${fullArray.length}`);
});
// Output (for each item):
// Item: apple, Position: 0, Total items: 4
// Item: banana, Position: 1, Total items: 4
// etc.
```

The third parameter (`fullArray`) is the original array itself — rarely needed, but handy for advanced cases.

**Example 4: Real-world DOM usage**

```js
const tasks = [
  { text: "Learn JS", done: true },
  { text: "Practice arrays", done: false },
  { text: "Build project", done: false }
];

// Imagine <ul id="taskList"></ul> in HTML
const ul = document.createElement("ul");

tasks.forEach(task => {
  const li = document.createElement("li");
  li.textContent = task.text;
  if (task.done) {
    li.style.textDecoration = "line-through";
  }
  ul.appendChild(li);
});

document.body.appendChild(ul);
```

This loops through an array of task objects and builds an HTML list — a pattern you'll see constantly in web apps.

### Key Characteristics

- **Does not return anything**: `const result = fruits.forEach(...);` → `result` is `undefined`
- **Cannot break early**: No `break` or `return` to stop the loop (use a `for` loop if you need that)
- **Does not skip empty slots** in sparse arrays (unlike some other methods)
- **Order is guaranteed**: Always from index 0 to the highest index

### Practice Solution with Explanation

**Problem:** Given an array of numbers `[5, 12, 8, 20, 3]`, use `.forEach()` to:
- Log each number multiplied by 2
- Count and log how many are greater than 10

**Solution Code:**

```js
const numbers = [5, 12, 8, 20, 3];
let countAboveTen = 0;

numbers.forEach(num => {
  console.log(num * 2);           // Log doubled value

  if (num > 10) {
    countAboveTen++;              // Increment counter
  }
});

console.log(`Numbers > 10: ${countAboveTen}`);
// Output:
// 10
// 24
// 16
// 40
// 6
// Numbers > 10: 2
```

**Explanation:**  
We use a single `.forEach()` loop to handle two side effects: logging doubled values and counting. The variable `countAboveTen` is declared outside the callback so it persists across iterations. This shows how `.forEach()` excels at performing multiple actions per element without creating new arrays.
