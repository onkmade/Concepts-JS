**In-depth explanation of how `Array.prototype.splice()` really works in JavaScript**

The `splice()` method is one of the most powerful (and sometimes confusing) array mutation methods because it can **do three different things at once** — and often does some combination of them:

1. **Remove** any number of elements from any position  
2. **Insert** any number of new elements at that same position  
3. **Replace** existing elements (by removing some + inserting new ones)

### Full signature
```js
array.splice(start, deleteCount?, item1?, item2?, ..., itemN?)
```

- **start** (required)  
  The index at which to start changing the array.  
  - Positive → counts from the beginning (0 = first element)  
  - Negative → counts from the end (-1 = last element, -2 = second-to-last, etc.)  
  - If > array.length → treated as array.length (appends to end)  
  - If < -array.length → treated as 0 (start from beginning)

- **deleteCount** (optional)  
  How many elements to **remove** starting from `start`.  
  - 0 → remove nothing (pure insertion)  
  - 1 or more → remove that many elements  
  - If omitted or > remaining elements → removes everything from `start` to end

- **item1, item2, …** (optional)  
  Elements to **insert** at the `start` position (after removals happen).  
  You can insert 0, 1, dozens, or even thousands of elements.

### What `splice()` actually returns
`splice()` **returns an array** containing all the **removed elements** (or an empty array if nothing was removed).

### Your exact example — step by step

```js
let arrOfShapes = ["circle", "triangle", "rectangle", "pentagon"];
// indices:           0        1         2          3

arrOfShapes.splice(2, 0, "square", "trapezoid");
```

Execution flow:

1. Start position = **2** → points at "rectangle"
2. deleteCount = **0** → remove **nothing**
3. Insert the new items **right before** index 2
   → "square" becomes the new index 2
   → "trapezoid" becomes the new index 3
4. Original "rectangle" gets pushed right → now at index 4
5. "pentagon" moves to index 5

Final array:
```js
["circle", "triangle", "square", "trapezoid", "rectangle", "pentagon"]
// indices:     0         1        2         3          4          5
```

And the return value of `splice()` in this case:
```js
[]   // empty array because deleteCount was 0 → nothing removed
```

### Most common real-world patterns

| Goal                                | splice call                              | Result (simplified)                     |
|-------------------------------------|------------------------------------------|------------------------------------------|
| Insert at position                  | `splice(2, 0, "new")`                    | inserts before index 2                   |
| Insert at the beginning             | `splice(0, 0, "first")`                  | like unshift()                           |
| Insert at the end                   | `splice(arr.length, 0, "last")`          | like push()                              |
| Remove 1 element                    | `splice(3, 1)`                           | removes index 3, returns [removedItem]   |
| Remove 3 elements                   | `splice(1, 3)`                           | removes 3 items starting at index 1      |
| Replace 2 elements                  | `splice(2, 2, "newA", "newB")`           | removes 2, inserts 2 → net size same     |
| Clear from index 2 to end           | `splice(2)` or `splice(2, arr.length)`   | removes everything from index 2 onward   |
| Delete last element                 | `splice(-1, 1)`                          | like pop()                               |

### Important notes & gotchas

- **Mutates the original array** (destructive method)  
- **Very performant** for most cases (better than many people think)  
- **Can be slow** only in extreme cases: inserting/removing thousands of elements at the beginning of a very large array (because everything has to shift)  
- `slice()` (with "c") is the non-destructive cousin → returns new array, doesn't change original

Bottom line:  
**`splice(start, 0, …items)` = insert**  
**`splice(start, count)` = remove**  
**`splice(start, count, …newItems)` = replace**
