`.toString()` and `.padStart()` are two very useful built-in string methods in JavaScript that help you format and convert data into clean, readable strings.

**`.toString()`** is a method that converts almost any value (number, boolean, object, array, etc.) into its string representation. It's the standard way to turn non-string values into strings when you need to display them, concatenate them, or send them somewhere that expects text. For numbers, it gives the cleanest string form without extra decimals, and for objects, it defaults to `"[object Object]"` unless you override it.

**`.padStart(length, filler)`** is a modern string method (ES2017) that adds characters (usually zeros or spaces) to the **beginning** of a string until it reaches the desired length. It's perfect for formatting numbers, codes, times, or IDs to always have a fixed width (e.g., "05" instead of "5", or "001" for a 3-digit code). There's also `.padEnd()` for adding to the end.

### Quick Examples

```js
// .toString()
console.log((42).toString());       // "42"
console.log((3.14).toString());     // "3.14"
console.log(true.toString());       // "true"
console.log([1, 2, 3].toString());  // "1,2,3"

// .padStart()
console.log("5".padStart(3, "0"));      // "005"
console.log("42".padStart(5, "*"));     // "***42"
console.log("7".padStart(2, "0"));      // "07" (perfect for time, dates, IDs)
console.log("hello".padStart(10));      // "     hello" (default filler is space)
```

### Real-Life Use

- Use `.toString()` whenever you need to concatenate numbers with strings: `"Score: " + score.toString()`
- Use `.padStart()` for displaying times ("09:05" instead of "9:5"), invoice numbers ("INV-000123"), progress ("05%"), or any fixed-width display.
