### The `.some()` and `.every()` Methods in Depth

These two array methods are **boolean testers** — they check conditions across the array and return `true` or `false`. They are incredibly useful for validation, enabling/disabling buttons, checking data states, or deciding what message to show the user.

#### `.some()` — "Does at least one element match?"

`.some()` loops through the array and returns `true` if **at least one** element passes the test (callback returns `true`). As soon as it finds one match, it stops looping and returns `true`. If no element matches, it returns `false`.

#### `.every()` — "Do all elements match?"

`.every()` loops through the array and returns `true` only if **every single element** passes the test. If even one element fails, it immediately returns `false`.

Both methods short-circuit (stop early) for efficiency.

### Basic Syntax

```js
array.some(callback);   // true if at least one passes
array.every(callback);  // true only if all pass
```

Callback returns a boolean, same parameters as before.

### Detailed Examples

**Example 1: Basic numbers**

```js
const numbers = [2, 4, 7, 8, 10];

// Is there at least one odd number?
const hasOdd = numbers.some(num => num % 2 !== 0);
console.log(hasOdd); // true (7 is odd)

// Are all numbers even?
const allEven = numbers.every(num => num % 2 === 0);
console.log(allEven); // false (7 is odd)
```

**Example 2: Array of tasks**

```js
const tasks = [
  { text: "Learn JS", done: true },
  { text: "Practice", done: false },
  { text: "Build project", done: false },
  { text: "Review", done: true }
];

// Is there any incomplete task?
const hasIncomplete = tasks.some(task => !task.done);
console.log(hasIncomplete); // true

// Are all tasks completed?
const allDone = tasks.every(task => task.done);
console.log(allDone); // false
```

**Example 3: User validation**

```js
const users = [
  { name: "Kiuru", age: 21 },
  { name: "Alex", age: 17 },
  { name: "Sam", age: 30 }
];

// Is there any underage user?
const hasMinor = users.some(user => user.age < 18);
console.log(hasMinor); // true

// Are all users adults?
const allAdults = users.every(user => user.age >= 18);
console.log(allAdults); // false
```

**Example 4: Real-world button enable/disable**

```js
const formFields = [
  { field: "name", filled: true },
  { field: "email", filled: true },
  { field: "password", filled: false }
];

// Can submit? Only if all fields are filled
const canSubmit = formFields.every(field => field.filled);
console.log("Can submit:", canSubmit); // false

// Show warning if any field is empty
const hasEmpty = formFields.some(field => !field.filled);
console.log("Has empty fields:", hasEmpty); // true
```

### Key Characteristics

- Both return **boolean** (`true`/`false`)
- Both **stop early** (short-circuit)
- Original array unchanged
- Great for validation and conditional logic

### Practice Solution with Explanation

**Problem:** Using the anime array:

```js
const animes = [
  { id: 1, name: "Kingwars", seasons: 5, genre: "Romance" },
  { id: 2, name: "The One Piece", seasons: 22, genre: "Adventure" },
  { id: 3, name: "Jujutsu Kaisen", seasons: 2, genre: "Action" },
  { id: 4, name: "Demon Slayer", seasons: 4, genre: "Action" }
];
```

Answer these questions with `.some()` and `.every()`:

- Is there any anime with more than 10 seasons?
- Is there any Romance anime?
- Are all animes Action genre?

**Solution Code:**

```js
// Any long-running anime?
const hasLongAnime = animes.some(anime => anime.seasons > 10);
console.log("Has long-running anime:", hasLongAnime); // true (One Piece)

// Any Romance?
const hasRomance = animes.some(anime => anime.genre === "Romance");
console.log("Has Romance:", hasRomance); // true

// All Action?
const allAction = animes.every(anime => anime.genre === "Action");
console.log("All Action:", allAction); // false
```

**Explanation:**  
`.some()` returns true as soon as it finds One Piece (22 seasons) or Kingwars (Romance). `.every()` fails immediately when it sees Kingwars or One Piece (not Action).
