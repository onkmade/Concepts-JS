# Strings

Strings in JavaScript are one of the most fundamental and frequently used data types in web development. A string is simply a sequence of characters used to represent text. In JS, strings are **primitive** values (immutable), meaning once created, their content cannot be changed — any operation that seems to modify a string actually creates a new one. You can create strings using single quotes `'hello'`, double quotes `"hello"`, or backticks `` `hello` `` (template literals). All three are valid, but backticks allow multiline strings and interpolation with `${expression}` — super useful for building dynamic HTML or messages.

Strings have a `.length` property that tells you how many characters they contain (including spaces and special characters). Indexing starts at 0, so you access individual characters with bracket notation: `str[0]` gives the first character. Note: strings are immutable, so `str[0] = 'X'` does nothing. Common methods include `.toUpperCase()` and `.toLowerCase()` for case conversion, `.trim()` to remove whitespace from both ends, `.trimStart()` and `.trimEnd()` for one side only — essential for cleaning user input from forms.

For searching and checking content, use `.includes("substring")` (returns true/false), `.startsWith()` and `.endsWith()` for prefixes/suffixes, and `.indexOf("sub")` (returns position or -1 if not found). To extract parts, `.slice(start, end)`, `.substring(start, end)`, or `.substr(start, length)` are available — `.slice()` is most flexible as it handles negative indices (counting from the end). Replacing text is done with `.replace("old", "new")` (replaces first match) or `.replaceAll("old", "new")` (all matches in modern JS).

Template literals (backticks) are a game-changer for building strings with variables or multiline text:

```js
const name = "Kiuru";
const age = 21;
const message = `Hello ${name}!
You are ${age} years old.
That's ${age >= 18 ? "adult" : "minor"} status.`;

console.log(message);
```

This avoids messy concatenation with `+` and makes code much more readable.

Splitting and joining are powerful for processing text:

```js
const sentence = "JavaScript is fun to learn";
const words = sentence.split(" ");         // ["JavaScript", "is", "fun", ...]
const csv = "apple,banana,orange";
const fruits = csv.split(",");             // ["apple", "banana", "orange"]

const joined = words.join("-");            // "JavaScript-is-fun-to-learn"
```

In web development, strings are everywhere: manipulating DOM text (`element.textContent = newString`), building URLs (`/user/${id}`), validating form inputs (checking email with `.includes("@")` and `.endsWith(".com")`), or formatting display data (currency, dates). Mastering string methods early makes handling user input, API responses, and dynamic content much easier.

Practice tip: take a user input string (like a tweet or comment), trim it, check length, convert to lowercase for search, replace bad words, and display the cleaned version.
