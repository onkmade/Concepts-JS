# Strings

Strings in JavaScript are one of the most fundamental and frequently used data types in web development. A string is simply a sequence of characters used to represent text. In JS, strings are **primitive** values (immutable), meaning once created, their content cannot be changed — any operation that seems to modify a string actually creates a new one. You can create strings using single quotes `'hello'`, double quotes `"hello"`, or backticks `` `hello` `` (template literals). All three are valid, but backticks allow multiline strings and interpolation with `${expression}` — super useful for building dynamic HTML or messages.

Strings have a `.length` property that tells you how many characters they contain (including spaces and special characters). Indexing starts at 0, so you access individual characters with bracket notation: `str[0]` gives the first character. Note: strings are immutable, so `str[0] = 'X'` does nothing. Common methods include `.toUpperCase()` and `.toLowerCase()` for case conversion, `.trim()` to remove whitespace from both ends, `.trimStart()` and `.trimEnd()` for one side only — essential for cleaning user input from forms.

For searching and checking content, use `.includes("substring")` (returns true/false), `.startsWith()` and `.endsWith()` for prefixes/suffixes, and `.indexOf("sub")` (returns position or -1 if not found). To extract parts, `.slice(start, end)`, `.substring(start, end)`, or `.substr(start, length)` are available — `.slice()` is most flexible as it handles negative indices (counting from the end). Replacing text is done with `.replace("old", "new")` (replaces first match) or `.replaceAll("old", "new")` (all matches in modern JS).

Template literals (backticks) are a game-changer for building strings with variables or multiline text:

```js
const name = "Kiuru";
const age = 21;
const message = `Hello ${name}!
You are ${age} years old.
That's ${age >= 18 ? "adult" : "minor"} status.`;

console.log(message);
```

This avoids messy concatenation with `+` and makes code much more readable.

Splitting and joining are powerful for processing text:

```js
const sentence = "JavaScript is fun to learn";
const words = sentence.split(" ");         // ["JavaScript", "is", "fun", ...]
const csv = "apple,banana,orange";
const fruits = csv.split(",");             // ["apple", "banana", "orange"]

const joined = words.join("-");            // "JavaScript-is-fun-to-learn"
```

In web development, strings are everywhere: manipulating DOM text (`element.textContent = newString`), building URLs (`/user/${id}`), validating form inputs (checking email with `.includes("@")` and `.endsWith(".com")`), or formatting display data (currency, dates). Mastering string methods early makes handling user input, API responses, and dynamic content much easier.

Practice tip: take a user input string (like a tweet or comment), trim it, check length, convert to lowercase for search, replace bad words, and display the cleaned version.

--- 
Here's a single, complete JavaScript program that demonstrates **all the major string methods** we've discussed, using one practical example: processing and displaying a user's comment (like in a blog or social app).

You can copy this entire code into your browser console or an HTML `<script>` tag to see it work.

```html
<!DOCTYPE html>
<html>
<head>
  <title>String Methods Demo</title>
</head>
<body>
  <h2>String Methods in Action</h2>
  <pre id="output"></pre>

  <script>
    // Original user input (messy, as real inputs often are)
    let userComment = "   hey kiuru!!! this is AWESOME    ";
    let badWord = "badword";
    let cleanComment = "This is a great post!";

    console.log("Original:", userComment);

    // 1. .trim() - remove whitespace from both ends
    let trimmed = userComment.trim();
    console.log("After trim():", trimmed); 
    // "hey kiuru!!! this is AWESOME"

    // 2. .toLowerCase() and .toUpperCase()
    let lower = trimmed.toLowerCase();
    let upper = trimmed.toUpperCase();
    console.log("Lowercase:", lower);
    console.log("Uppercase:", upper);

    // 3. .includes() - check if contains substring
    let hasKiuru = lower.includes("kiuru");
    console.log("Mentions Kiuru?", hasKiuru); // true

    // 4. .startsWith() and .endsWith()
    console.log("Starts with 'hey'?", lower.startsWith("hey")); // true
    console.log("Ends with 'awesome'?", lower.endsWith("awesome")); // true

    // 5. .replace() and .replaceAll()
    let polite = trimmed.replace("AWESOME", "great"); // only first match
    console.log("After replace:", polite);

    // Simulate cleaning bad words
    let safeComment = cleanComment.replaceAll("badword", "*****");
    console.log("Censored:", safeComment);

    // 6. .indexOf() - find position
    let pos = lower.indexOf("kiuru");
    console.log("Position of 'kiuru':", pos); // 4

    // 7. .slice() - extract part of string
    let greeting = lower.slice(0, 3); // "hey"
    let mainPart = lower.slice(4);    // "kiuru!!! this is great"
    console.log("Greeting:", greeting);
    console.log("Main part:", mainPart);

    // 8. .split() and .join()
    let words = trimmed.split(" "); // split into array
    console.log("Words array:", words);

    let dashed = words.join("-");
    console.log("Joined with dash:", dashed); 
    // "hey-kiuru!!!-this-is-AWESOME"

    // 9. Template literals (backticks) - dynamic strings
    let formattedComment = `
      User said: "${trimmed}"
      Word count: ${words.length}
      Cleaned version: ${polite}
      Status: ${hasKiuru ? "Mentioned you!" : "No mention"}
    `;

    console.log(formattedComment);

    // 10. .length - get string length
    console.log("Original length:", userComment.length);
    console.log("Trimmed length:", trimmed.length);

    // Display in HTML
    document.getElementById("output").textContent = formattedComment;
  </script>
</body>
</html>
```

### What this program shows (all methods in one place):

- `.trim()` → clean user input  
- `.toLowerCase()` / `.toUpperCase()` → normalize text  
- `.includes()` → check content  
- `.startsWith()` / `.endsWith()` → validate prefixes  
- `.replace()` / `.replaceAll()` → censor or format  
- `.indexOf()` → find position  
- `.slice()` → extract parts  
- `.split()` + `.join()` → process words  
- **Template literals** → build nice output  
- `.length` → count characters  

This example covers all the key string methods and properties, demonstrating how they can be used together in a practical scenario. Experiment with changing the `userComment` variable to see how different inputs are processed!
