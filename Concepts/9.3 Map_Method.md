### The `.map()` Method in Depth

The `.map()` method is one of the most powerful and frequently used array methods in JavaScript. It loops through every element in an array, applies a transformation function to each element, and returns a **new array** containing the results. The original array remains completely unchanged — this makes `.map()` **immutable** and safe to use without worrying about side effects. It is the go-to method whenever you need to create a modified version of an array, such as formatting data for display, extracting specific properties from objects, or converting values (e.g., strings to numbers, Celsius to Fahrenheit).

Unlike `.forEach()`, which is only for side effects (like logging or DOM updates) and returns `undefined`, `.map()` always returns a **new array** of the same length as the original. This new array contains whatever value you `return` from the callback function for each element. If you forget to `return` something, the new array will be filled with `undefined`.

### Basic Syntax

```js
const newArray = array.map(callbackFunction);

// Callback receives the same three parameters as .forEach():
// 1. currentElement (required)
// 2. index (optional)
// 3. array (optional)
const newArray = array.map((element, index, array) => {
  return transformedValue;  // MUST return something!
});
```

### Detailed Examples

**Example 1: Basic transformation (double numbers)**

```js
const numbers = [1, 2, 3, 4, 5];

const doubled = numbers.map(num => num * 2);
console.log(doubled);     // [2, 4, 6, 8, 10]
console.log(numbers);     // [1, 2, 3, 4, 5] → original unchanged!
```

**Example 2: Extracting properties from array of objects**

```js
const users = [
  { name: "Kiuru", age: 21 },
  { name: "Alex", age: 25 },
  { name: "Sam", age: 30 }
];

const names = users.map(user => user.name);
console.log(names); 
// ["Kiuru", "Alex", "Sam"]

const greetings = users.map(user => `Hello ${user.name}!`);
console.log(greetings); 
// ["Hello Kiuru!", "Hello Alex!", "Hello Sam!"]
```

This is **extremely common** in web development when you have API data and want just part of it.

**Example 3: Using index for numbered list**

```js
const fruits = ["apple", "banana", "orange"];

const numbered = fruits.map((fruit, index) => `${index + 1}. ${fruit.toUpperCase()}`);
console.log(numbered); 
// ["1. APPLE", "2. BANANA", "3. ORANGE"]
```

**Example 4: Real-world HTML generation**

```js
const tasks = [
  { text: "Learn map()", done: true },
  { text: "Practice daily", done: false },
  { text: "Build project", done: false }
];

// Create array of HTML strings
const htmlItems = tasks.map(task => {
  const style = task.done ? "text-decoration: line-through;" : "";
  return `<li style="${style}">${task.text}</li>`;
});

console.log(htmlItems.join(""));
// <li style="text-decoration: line-through;">Learn map()</li><li style="">Practice daily</li><li style="">Build project</li>
```

You can then insert this into the DOM with `ul.innerHTML = htmlItems.join("")`.

### Key Characteristics

- Always returns a **new array** of the same length
- Original array is **never mutated**
- You **must `return`** a value in the callback — otherwise you get `undefined`
- Great for data transformation and preparing data for display

### Practice Solution with Explanation

**Problem:** Given an array of prices `[19.99, 45.50, 9.99, 120.00]`, use `.map()` to:
- Create a new array with prices formatted as strings with "$" and 2 decimal places
- Create another array with 20% tax added

**Solution Code:**

```js
const prices = [19.99, 45.50, 9.99, 120.00];

// Formatted prices
const formatted = prices.map(price => `$${price.toFixed(2)}`);
console.log(formatted); 
// ["$19.99", "$45.50", "$9.99", "$120.00"]

// Prices with 20% tax
const withTax = prices.map(price => price * 1.20);
const taxedFormatted = withTax.map(price => `$${price.toFixed(2)}`);
console.log(taxedFormatted); 
// ["$23.99", "$54.60", "$11.99", "$144.00"]

// One-liner chaining (advanced but clean)
const final = prices
  .map(price => price * 1.20)
  .map(price => `$${price.toFixed(2)}`);

console.log(final);
```

**Explanation:**  
We use `.map()` twice: first to calculate tax, then to format as currency. Each `.map()` returns a new array, so we can chain them. The original `prices` array stays untouched. This chaining pattern is very common in real apps when processing data from APIs.

`.map()` will quickly become your favorite method — it’s clean, predictable, and essential for transforming data.

## Some understandng about arrow functions and implicit return
The two lines you provided highlight a critical difference in how JavaScript handles **arrow function syntax** in the `.map()` method:

```js
const doubled = numbers.map(num => num * 2);          // Works
const doubled = numbers.map(num => { num * 2 });      // Doesn't work as expected
```

### Why the second line doesn't work

The issue is with the **block body** in the arrow function (using curly braces `{}`) and the **lack of an explicit `return` statement**.

In JavaScript, arrow functions behave differently depending on whether you use:
- **Implicit return** (no curly braces)
- **Explicit return** (with curly braces)

### Explanation of Each Line

**1. First Line (Works):**

```js
const doubled = numbers.map(num => num * 2);
```

- This uses an **implicit return** arrow function.
- When you write an arrow function **without curly braces**, the expression after `=>` is automatically returned.
- Here, `num * 2` is evaluated for each `num`, and the result is returned to `.map()`, which collects it into the new array.
- Example:

```js
const numbers = [1, 2, 3];
const doubled = numbers.map(num => num * 2);
console.log(doubled); // [2, 4, 6]
```

**2. Second Line (Doesn't work as expected):**

```js
const doubled = numbers.map(num => { num * 2 });
```

- This uses an arrow function with a **block body** (curly braces `{}`).
- In a block body, JavaScript treats the code inside as a regular function body, and **you must explicitly write `return`** to send a value back.
- Without `return`, the function evaluates `num * 2` but **discards the result**, and the function implicitly returns `undefined`.
- Since `.map()` collects the return value of the callback for each element, you get an array filled with `undefined`:

```js
const numbers = [1, 2, 3];
const doubled = numbers.map(num => { num * 2 });
console.log(doubled); // [undefined, undefined, undefined]
```

### How to Fix the Second Line

To make the second line work, you need to add an explicit `return`:

```js
const doubled = numbers.map(num => { return num * 2 });
```

Now it behaves the same as the first line:

```js
const numbers = [1, 2, 3];
const doubled = numbers.map(num => { return num * 2 });
console.log(doubled); // [2, 4, 6]
```

### When to Use Braces vs. No Braces

- **No braces (implicit return)**: Use when your callback is a single expression and you want to return its result directly. It's concise and common for `.map()`.

```js
numbers.map(num => num * 2)
numbers.map(num => `$${num}`)
```

- **Braces (explicit return)**: Use when you need multiple statements inside the callback (e.g., logging, conditionals, or complex logic). You must use `return` to send a value back to `.map()`.

```js
numbers.map(num => {
  const result = num * 2;
  console.log(`Doubling ${num}`);
  return result;
});
```

### Why This Matters for `.map()`

The `.map()` method **relies on the return value** of the callback to build the new array. If the callback doesn't return anything (or returns `undefined`), the new array will have `undefined` for that element. This is why the second line gave you unexpected results — you were missing the `return`.

### Practice to Solidify

Try this in your console:

```js
const numbers = [5, 10, 15];

// Try without braces
console.log(numbers.map(n => n + 1)); // [6, 11, 16]

// Try with braces but no return
console.log(numbers.map(n => { n + 1 })); // [undefined, undefined, undefined]

// Fix with return
console.log(numbers.map(n => { return n + 1 })); // [6, 11, 16]
```

### Summary

- **Without braces** (`num => num * 2`): Automatically returns the expression — perfect for simple `.map()` transformations.
- **With braces** (`num => { num * 2 }`): Acts like a regular function body, so you **must use `return`** or you get `undefined`.
- Always ensure `.map()` gets a return value, or you'll end up with an array of `undefined`.
