### The `.filter()` Method in Depth

The `.filter()` method is another essential array method that lets you create a **new array** containing only the elements that pass a certain test (condition). It loops through the original array, runs your callback function on each element, and includes the element in the new array **only if the callback returns `true`**. If the callback returns `false`, the element is skipped. Like `.map()`, `.filter()` is immutable — it never changes the original array — and it returns a new array that can be shorter (or even empty) if no elements pass the test.

`.filter()` is perfect for selecting subsets of data: showing only completed tasks, filtering products under a price, displaying active users, or searching items that match a query. It's one of the most used methods in real web apps because data often needs to be narrowed down before display or processing.

### Basic Syntax

```js
const newArray = array.filter(callbackFunction);

// Callback receives the same three parameters:
// 1. element (required)
// 2. index (optional)
// 3. array (optional)
// Must return a boolean (true/false)
const newArray = array.filter((element, index, array) => {
  return booleanCondition;
});
```

### Detailed Examples

**Example 1: Filter even numbers**

```js
const numbers = [1, 2, 3, 4, 5, 6, 7, 8];

const evens = numbers.filter(num => num % 2 === 0);
console.log(evens);       // [2, 4, 6, 8]
console.log(numbers);     // Original unchanged: [1, 2, 3, 4, 5, 6, 7, 8]
```

**Example 2: Filter objects by property**

```js
const users = [
  { name: "Kiuru", age: 21, active: true },
  { name: "Alex", age: 25, active: false },
  { name: "Sam", age: 30, active: true },
  { name: "Jordan", age: 18, active: false }
];

const activeUsers = users.filter(user => user.active);
console.log(activeUsers);
// [{name: "Kiuru", age: 21, active: true}, {name: "Sam", age: 30, active: true}]

const adults = users.filter(user => user.age >= 18);
console.log(adults.length); // 4 (all of them)
```

**Example 3: Filter strings by condition**

```js
const fruits = ["apple", "banana", "kiwi", "orange", "grape"];

const longFruits = fruits.filter(fruit => fruit.length > 5);
console.log(longFruits); // ["banana", "orange"]

const startsWithA = fruits.filter(fruit => fruit.startsWith("a"));
console.log(startsWithA); // ["apple"]
```

**Example 4: Real-world search filter**

```js
const products = [
  { name: "Laptop", price: 999, inStock: true },
  { name: "Mouse", price: 25, inStock: true },
  { name: "Keyboard", price: 75, inStock: false },
  { name: "Monitor", price: 299, inStock: true }
];

const affordableInStock = products.filter(product => 
  product.price <= 100 && product.inStock
);
console.log(affordableInStock);
// [{name: "Mouse", price: 25, inStock: true}]
```

### Key Characteristics

- Returns a **new array** (possibly shorter or empty)
- Original array **unchanged**
- Callback must return a **boolean** (`true` to keep, `false` to skip)
- Often combined (chained) with `.map()` for powerful data processing

### Practice Solution with Explanation

**Problem:** Given an array of tasks `[{text: "Learn JS", done: true}, {text: "Practice", done: false}, ...]`, use `.filter()` to:
- Create an array of only incomplete tasks
- Create an array of tasks with text longer than 10 characters

**Solution Code:**

```js
const tasks = [
  { text: "Learn JavaScript", done: true },
  { text: "Practice arrays", done: false },
  { text: "Build a project", done: false },
  { text: "Review code", done: true },
  { text: "Sleep", done: false }
];

// Incomplete tasks
const todo = tasks.filter(task => !task.done);
console.log("To do:", todo);
// [{text: "Practice arrays", ...}, {text: "Build a project", ...}, {text: "Sleep", ...}]

// Long tasks
const longTasks = tasks.filter(task => task.text.length > 10);
console.log("Long tasks:", longTasks);
// [{text: "Learn JavaScript"}, {text: "Practice arrays"}, {text: "Build a project"}]

// Chain: incomplete AND long
const importantTodo = tasks.filter(task => !task.done && task.text.length > 10);
console.log("Important to do:", importantTodo);
// [{text: "Practice arrays"}, {text: "Build a project"}]
```

**Explanation:**  
We use simple boolean conditions in the callback. `!task.done` means "not done" (incomplete). Chaining multiple conditions with `&&` or `||` inside `.filter()` is very common for complex searches. The result is always a new array with only matching items.

### How `.filter()` Differs from `.map()`
```js
const numbers = [2, 3, 4, 16, 65, 244, 576, 5, 100, 15, 20, 25];
const doubled = numbers.map( num => num * 2);
console.log(numbers); // original array
console.log(doubled); // doubled array

const filtering = numbers.filter( num => num % 2 === 0);
console.log(filtering); // filtered array numbers based on condition

const filter  = numbers.map( num => num % 2 === 0);
console.log(filter);  // gives true true false false cause num % 2 === 0, always returns the true/false
```
