Here’s a clear, in-depth comparison of the three most important **array modification methods** in JavaScript:  
**push()**, **concat()**, and **splice()**

| Method       | Mutates original array? | Returns what?                          | Main purpose                              | Speed (typical case) | Most common use case                              |
|--------------|---------------------------|----------------------------------------|-------------------------------------------|----------------------|---------------------------------------------------|
| `push()`     | Yes                       | new length of the array                | Add **one or more** elements **to the end**     | Very fast (O(1))     | Adding new items to a list/stack                  |
| `concat()`   | **No**                    | **New** array with combined elements   | Create new array by combining arrays/values     | O(n)                 | Merging arrays without changing originals         |
| `splice()`   | Yes                       | Array of **removed** elements          | Insert / remove / replace **anywhere**          | O(n)                 | Surgical changes in the middle of array           |

### Detailed comparison with examples

```javascript
let fruits = ["apple", "banana"];

// 1. push() ────────────────────────────────────────────────
fruits.push("mango", "kiwi");          // adds to the END

console.log(fruits);      
// ["apple", "banana", "mango", "kiwi"]

let newLength = fruits.push("orange");  
console.log(newLength);                // 5  ← returns new length
```

```javascript
// 2. concat() ──────────────────────────────────────────────
let moreFruits = ["pineapple", "grapes"];

let allFruits = fruits.concat(moreFruits, "dragonfruit");
// or: fruits.concat(["pineapple"], "grapes", ["dragonfruit"])

console.log(allFruits);  
// ["apple","banana","mango","kiwi","orange","pineapple","grapes","dragonfruit"]

console.log(fruits);     
// ["apple","banana","mango","kiwi","orange"]   ← original unchanged!
```

```javascript
// 3. splice() ──────────────────────────────────────────────
// Most flexible & powerful (but also most dangerous)

let animals = ["cat", "dog", "rabbit", "hamster"];

// Insert without removing
animals.splice(2, 0, "parrot", "fish");
//        start  delete  items to insert
console.log(animals);
// ["cat", "dog", "parrot", "fish", "rabbit", "hamster"]

// Remove 2 items
let removed = animals.splice(1, 2);     // starts at index 1, removes 2
console.log(removed);                   // ["dog", "parrot"]
console.log(animals);                   // ["cat", "fish", "rabbit", "hamster"]

// Replace (remove 1 + insert 2)
animals.splice(1, 1, "turtle", "snake");
console.log(animals);
// ["cat", "turtle", "snake", "rabbit", "hamster"]
```

### Quick decision table – which to use when?

```text
You want to...                                → Use this
──────────────────────────────────────────────┼──────────────
Add item(s) at the **end**                    → push()
Add item(s) at the **beginning**              → unshift() (not in this comparison)
Create **new array** by combining arrays      → concat() / spread [...arr1, ...arr2]
Insert in the **middle** / at specific index  → splice()
**Replace** some elements with others         → splice()
**Remove** elements from specific position    → splice()
Remove **last** element (and get it)          → pop()
Remove **first** element (and get it)         → shift()
```

### Modern alternatives people use a lot (2024–2026)

```javascript
// Instead of push() when you want new array:
[...fruits, "pear", "melon"]

// Instead of concat():
[...fruits, ...moreFruits, "cherry"]

// Instead of splice() for simple insert (sometimes more readable):
fruits = [
  ...fruits.slice(0, 2),
  "newItem",
  ...fruits.slice(2)
];
```

### Summary – one-liners to remember

- `push()` → **"add to end, mutate, fast, returns length"**  
- `concat()` → **"merge without touching original, returns new array"**  
- `splice()` → **"Swiss army knife: insert/remove/replace anywhere, mutates, returns removed items"**

Most professional code today uses:  
`push()` + `concat()` + spread operator a lot,  
and `splice()` mainly when you **really** need to change the array in the middle.
