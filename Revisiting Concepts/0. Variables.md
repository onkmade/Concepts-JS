   **Variables: Complete Summary**

---

## 1. Definition
A **variable** is a named container that stores data values for later use in a program.

---

## 2. Declaration Keywords
| Keyword | Scope | Reassign? | Redeclare? | Best Practice |
|---------|-------|-----------|------------|---------------|
| `var` | Function | ✓ | ✓ | Avoid (legacy) |
| `let` | Block | ✓ | ✗ | Use when value changes |
| `const` | Block | ✗ | ✗ | **Default choice** |

---

## 3. Core Components
```javascript
const   age    =    25   ;
│       │      │    │
│       │      │    └── Literal (actual value)
│       │      └────── Assignment operator
│       └───────────── Identifier (variable name)
└───────────────────── Keyword (declaration type)
```

---

## 4. Data Types (JavaScript)
- **Primitive**: `string`, `number`, `boolean`, `null`, `undefined`, `symbol`, `bigint`
- **Reference**: `object`, `array`, `function`

---

## 5. Scope (Visibility)
| Type | Accessibility |
|------|---------------|
| **Global** | Everywhere |
| **Function/Local** | Inside function only |
| **Block** | Inside `{}` only (`let`, `const`) |

---

## 6. Key Concepts
| Concept | Meaning |
|---------|---------|
| **Literal** | Hardcoded value (`42`, `"text"`) |
| **Identifier** | Variable name chosen by programmer |
| **Hoisting** | Variables lifted to top of scope (var only) |
| **Closure** | Inner function retains access to outer scope |
| **Label** | Code location marker (`loopName:`), not a variable |

---

## 7. Best Practices
```javascript
// ✅ Use const by default
const PI = 3.14159;

// ✅ Use let for changing values
let count = 0;
count++;

// ✅ Descriptive identifiers
const userName = "Alice";  // Not: x, n, tmp

// ❌ Avoid var
var oldStyle = "problem";  // Function-scoped, hoisted issues
```

---

**Fundamental rule**: Variables make code dynamic, reusable, and readable by separating data from logic.
