1. Create an array of 5 numbers. Use while loop to print only the even numbers from the array.

2. Create an array of names. Use while loop + condition to print only names that have length > 4.

3. Create an empty array. Use while loop to ask user for numbers (using prompt) and add them to array until user enters 0.

4. Create array of 8 numbers. Use while loop to find and print the biggest number in the array.

5. Create object with property "score" = 0. Use while loop to increase score by 10 each time until score >= 100, then print "Level complete!".

6. Create array of objects (at least 4), each with {name, age}. Use while loop to print only names of people older than 18.

7. Create array of numbers. Use while loop to count how many numbers are positive, negative and zero.

8. Create object {money: 500, debt: 1200}. Use while loop to subtract 150 from debt and add 150 to money until debt <= 0. Print final money and "Debt free!".

9. Create array of shopping items (strings). Use while loop + prompt to ask user "Do you want to buy more? (yes/no)" and keep adding new items until answer is not "yes".

10. Create array of temperatures (numbers). Use while loop to count how many days had temperature >= 30.

11. Create array of objects {product, price}. Use while loop to calculate and print total price of all products.

12. Create empty array "attempts". Use while loop + prompt to ask for password until correct ("secret123"). Each wrong attempt pushes current guess to array. At the end print how many attempts and list of wrong guesses.

13. Create object player {health: 100, level: 1}. Use while loop: while health > 0 decrease health by random 10–30 and increase level by 1. Stop when health <= 0 and print final level.

14. Create array of words. Use while loop to create new array that contains only words starting with letter "a" or "A".

15. Create array of student objects {name, marks}. Use while loop to find and print name of student with highest marks.

16. Create array of numbers. Use while loop + condition to remove all numbers smaller than 10 from the beginning of array (use shift() inside while).

17. Create object {balance: 1000}. Use while loop + prompt to keep asking "Withdraw how much?" and subtract from balance until balance < 100. Print "Low balance warning!".

18. Create array of colors. Use while loop to ask user to guess your favorite color from the array. Give hints ("warmer"/"colder") based on alphabetical order until correct.

19. Create two arrays: names[] and ages[]. Use while loop to create array of objects that contain matching name-age pairs.

20. Create array of mixed values (numbers + strings + booleans). Use while loop to create 3 separate arrays: one for numbers, one for strings, one for booleans.
