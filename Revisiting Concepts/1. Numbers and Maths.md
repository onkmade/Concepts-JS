### 1. Core Number Types & Gotchas (Quick Review + Depth)

In javascript, numbers are one of the most fundamental data types, but they come with some important characteristics and quirks that trip up many developers, especially those new to programming or coming from languages with more distinct numeric types.

JavaScript has **only one number type**: 64-bit floating point (IEEE 754 double precision).  
That means:
- Integers (1, 42, -7)
- Decimals (3.14, 0.1)
- Very large/small numbers (1e20, 1e-10)

**Important gotcha everyone hits** (floating-point precision):

```js
console.log(0.1 + 0.2);     // 0.30000000000000004   ← not 0.3
console.log(0.1 + 0.2 === 0.3); // false
```

**Why?** Computers store decimals in binary, and some fractions (like 0.1) can't be represented exactly — same reason 1/3 = 0.333… forever in decimal.  
**Solution for money/finance** — never use floats directly:

```js
// Bad
const total = 0.1 + 0.2; // unreliable

// Good (work in cents)
const priceCents = 10; // $0.10
const taxCents = 20;  // $0.20
const totalCents = priceCents + taxCents;
const totalDollars = totalCents / 100; // 0.3
console.log(totalDollars.toFixed(2)); // "0.30"
```

### 2. Important Number Methods & Properties

| Method/Property          | What it does                                      | Example & Output                           |
|--------------------------|---------------------------------------------------|--------------------------------------------|
| `.toFixed(n)`            | Rounds to n decimal places, returns string        | `(3.14159).toFixed(2)` → `"3.14"`          |
| `.toPrecision(n)`        | Total significant digits                          | `(123.456).toPrecision(4)` → `"123.5"`     |
| `Number.isInteger(x)`    | Checks if value is integer                        | `Number.isInteger(42)` → `true`            |
| `Number.isNaN(x)`        | True only for actual NaN (not `"NaN"`, `null`, etc.) | `Number.isNaN(NaN)` → `true`               |
| `Number.parseInt(str, radix)` | Parses string to integer (radix = base, usually 10) | `Number.parseInt("42px", 10)` → `42`       |
| `Number.parseFloat(str)` | Parses string to floating-point                   | `Number.parseFloat("3.14")` → `3.14`       |
| `Math.floor(x)`          | Rounds down to nearest integer                    | `Math.floor(3.9)` → `3`                    |
| `Math.ceil(x)`           | Rounds up                                         | `Math.ceil(3.1)` → `4`                     |
| `Math.round(x)`          | Rounds to nearest integer                         | `Math.round(3.5)` → `4`                    |
| `Math.random()`          | Random float 0 ≤ x < 1                            | `Math.random()` → e.g. 0.723...            |
| `Math.min(...numbers)`   | Smallest number                                   | `Math.min(5, 2, 9)` → `2`                  |
| `Math.max(...numbers)`   | Largest number                                    | `Math.max(5, 2, 9)` → `9`                  |

### 3. Generating Random Integers (Most Common Real Use)

```js
// Random integer from min to max (inclusive)
function randomInt(min, max) {
  return Math.floor(Math.random() * (max - min + 1)) + min;
}

console.log(randomInt(1, 10));   // 1–10
console.log(randomInt(100, 200)); // 100–200
```

### 4. Real-World Examples

**Currency formatting (always safe)**

```js
const price = 1999; // cents
console.log(`$${ (price / 100).toFixed(2) }`); // "$19.99"
```

**Random color generator**

```js
function randomColor() {
  return `rgb(${randomInt(0,255)}, ${randomInt(0,255)}, ${randomInt(0,255)})`;
}
document.body.style.backgroundColor = randomColor();
```

**Rounding for display**

```js
const avgRating = 4.666;
console.log(avgRating.toFixed(1)); // "4.7"
```
