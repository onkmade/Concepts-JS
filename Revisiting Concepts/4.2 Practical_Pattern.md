work with arrays using `while` loops (practical patterns you should know):

```javascript
let arr = [10, 7, 15, 3, 22, 8, 41, 9];
```

### 1. Go through the entire array (most basic & important)

```js
let i = 0;
while (i < arr.length) {
    console.log(arr[i]);
    i++;          // don't forget this!
}
```

### 2. Process only some elements (with condition)

```js
let i = 0;
while (i < arr.length) {
    if (arr[i] % 2 === 0) {
        console.log("Even:", arr[i]);
    }
    i++;
}
```

### 3. Find first element that satisfies condition

```js
let i = 0;
let found = null;

while (i < arr.length) {
    if (arr[i] > 20) {
        found = arr[i];
        break;           // ← stop immediately
    }
    i++;
}
console.log("First > 20:", found);   // 22
```

### 4. Sum / count while looping

```js
let i = 0;
let sum = 0;
let countEven = 0;

while (i < arr.length) {
    sum += arr[i];
    
    if (arr[i] % 2 === 0) {
        countEven++;
    }
    
    i++;
}

console.log("Sum:", sum);
console.log("Even numbers count:", countEven);
```

### 5. Build new array (filter-like behavior)

```js
let i = 0;
let bigNumbers = [];

while (i < arr.length) {
    if (arr[i] > 10) {
        bigNumbers.push(arr[i]);
    }
    i++;
}

console.log(bigNumbers);   // [15, 22, 41]
```

### 6. Modify array while looping (be careful!)

```js
// Careful version - going forward
let i = 0;
while (i < arr.length) {
    if (arr[i] < 10) {
        arr.splice(i, 1);    // remove element
        // do NOT do i++ here!
    } else {
        i++;
    }
}
```

```js
// Safer & easier: go backwards
let i = arr.length - 1;
while (i >= 0) {
    if (arr[i] < 10) {
        arr.splice(i, 1);
    }
    i--;
}
```

### Quick cheat-sheet – most frequent while + array patterns

```text
Goal                              Pattern you usually want
────────────────────────────────────────────────────────────────
Read every element                while (i < arr.length) { ... i++ }
Find something                    while (i < arr.length) { if(...) break; }
Count / sum                       while (...) { sum += arr[i]; i++ }
Build new array                   while (...) { if(...) newArr.push(...); i++ }
Remove elements                   better backwards OR collect indices first
Replace elements                  while (...) { if(...) arr[i] = newValue; i++ }
```

**Most important advice right now:**

Whenever you use `while` with array →  
**always** have a variable `i` (or `index`)  
**always** increase it (`i++`)  
**always** check `i < arr.length` as condition

These are the foundations — almost every array loop pattern builds on these.
