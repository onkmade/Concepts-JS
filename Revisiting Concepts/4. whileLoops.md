### While Loop – The Most Fundamental Loop

The `while` loop repeats a block of code **as long as a condition is true**.

```javascript
while (condition) {
    // code that runs repeatedly
    // usually we change something inside so the condition eventually becomes false
}
```

### Most Important Pattern – Controlled while loop (counting)

```javascript
let count = 1;

while (count <= 5) {
    console.log("Count is:", count);
    count = count + 1;     // ← VERY IMPORTANT! (or count++)
}

console.log("Loop finished!");
```

Output:
```
Count is: 1
Count is: 2
Count is: 3
Count is: 4
Count is: 5
Loop finished!
```

### Real classic examples using while

1. Ask user until correct answer
```javascript
let answer = "";

while (answer !== "yes") {
    answer = prompt("Are you ready? (type yes)");
}
console.log("Great! Let's begin!");
```

2. Simple sum until user says stop
```javascript
let sum = 0;
let number = Number(prompt("Enter a number (0 to stop):"));

while (number !== 0) {
    sum = sum + number;
    number = Number(prompt("Enter next number (0 to stop):"));
}

console.log("Total sum:", sum);
```

### Very Important while loop dangers & patterns

```javascript
// INFINITE LOOP (very dangerous – browser may freeze!)
while (true) {
    console.log("This never stops...");
}

// Safe version with break
while (true) {
    let input = prompt("Type 'stop' to exit");
    if (input === "stop") {
        break;           // ← immediately exits the loop
    }
    console.log("You typed:", input);
}
```

### Quick summary table – while loop essentials

| Pattern                     | Typical code fragment                              | When to use it                                  |
|-----------------------------|----------------------------------------------------|-------------------------------------------------|
| Count from 1 to n           | `let i=1; while(i<=n){...; i++}`                   | Known number of repetitions                     |
| Wait for user input         | `while(answer !== "yes") { answer = prompt(...) }` | Need to keep asking until condition met         |
| Process until 0/sentinel    | `while(number !== 0){ sum += number; ... }`        | Process items until special "stop" value        |
| Game loop / infinite until break | `while(true){ if(condition) break; ... }`       | Main game loop, menu, etc.                      |

### Next natural steps after you feel comfortable with `while`

Once you master `while`, the usual recommended learning order is:

1. `while` (you are here)  
2. `do...while` (runs at least once)  
3. `for` loop (best for counting / known number of times)  
4. `for...of` (modern way to loop over arrays)  
5. `forEach`, `map`, `filter`, etc. (array methods – very powerful later)
